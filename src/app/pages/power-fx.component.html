terminal Power Fx Formules & Instructies

Hieronder vind je de gevraagde Power Fx implementatie-details, de SharePoint lijsten structuur en oplossingen voor in een echte Power App omgeving.

1 & 2. Filteren van Leerlingen en Docenten

Filter(
    Leerlingen;
    Schooljaar = "2026-2027" && 
    Actief = true &&
    Klas = ddbKlas.Selected.Value
)

3 & 4. Opslaan Memo's (Patch)

Patch(
    MemoTW1TW2;
    Defaults(MemoTW1TW2);
    {
        Schooljaar: "2026-2027";
        Toetsweek: { Value: ddbToetsweek.Selected.Value }; 
        Leerlingnummer: ddbLeerling.Selected.Leerlingnummer;
        ...
    }
);;

5 & 6. Opslaan Mentorvoorbeiding en Voortgangsplan

UpdateContext({
    varBestaand: LookUp(
        MentorVoorbereiding;
        Leerlingnummer = ddbLeerling.Selected.Leerlingnummer &&
        Periode.Value = ddbPeriode.Selected.Value
    )
});;

Patch(
    MentorVoorbereiding;
    If(IsBlank(varBestaand); Defaults(MentorVoorbereiding); varBestaand);
    {
        Schooljaar: "2026-2027";
        ...
    }
);;

7. Samenstellen van aandachtspunten

Concat(
    Filter(
        Table(
            { Check: ThisItem.AandachtInhoudelijkBegrip; Naam: "Inhoudelijk begrip" };
            ...
        );
        Check = true
    );
    Naam;
    ", "
)
